# Git development

Paths in the repository map are relative to the repository root.

## Project Map

| Component | Responsibility | Repository |
|-----------|----------------|------------|
| Editor | Browser editor UI and PDF preview | [siglum-web](https://github.com/SiglumProject/siglum-web) |
| Engine | WebAssembly LaTeX compilation and TeX package loading | [siglum](https://github.com/SiglumProject/siglum) |
| Filesystem | Local OPFS and IndexedDB storage | [siglum-filesystem](https://github.com/SiglumProject/siglum-filesystem) |
| Git | Repository storage, synchronization, and conflict handling | [siglum-git](https://github.com/SiglumProject/siglum-git) |

## Repository Map

| Path | Purpose |
|------|---------|
| `src/index.ts` | Public package exports |

| `src/OPFSGitAdapter.ts` | Standalone OPFS adapter |
| `src/RepositoryReplacement.ts` | Staged repository replacement and recovery snapshots |
| `src/types.ts` | Connection, status, file, and conflict types |
| `tests/git-filesystem.test.ts` | Adapter, data preservation, synchronization, and conflict regressions |
| `package.json`, `tsconfig.json` | Dependencies, published entry point, commands, and build settings |
| `dist/` | JavaScript and declarations generated by `bun run build` |

## Development

The local dependency override in `package.json` points to
`../siglum-filesystem`. Keep that sibling checkout available and build it before
building this package.

```bash
bun install
bun run build
bun test
```

`bun run dev` watches TypeScript. `bun test tests/git-filesystem.test.ts` runs the
filesystem and repository regression suite. Its fixtures use temporary local
repositories and clean them up after each test. Contributor guidance is in
[AGENTS.md](../AGENTS.md).
